# LGSM Reference Snapshot

These files are archived reference exports that were previously kept at repo
root.

- `lgsm_full_list.csv` is a snapshot of LGSM short ids, AlphaGSM module ids,
  game names, and the runtime baseline noted when the export was created.
- `lgsm_ids.txt` is the matching plain-text short-id list.

They are not active configuration inputs for AlphaGSM itself, but they remain
useful as historical/reference data.
