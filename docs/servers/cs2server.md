# cs2server

`cs2server` is an alias for [`counterstrike2`](counterstrike2.md).

This alias points at the `PASSED` current CS2 path on the documented Ubuntu
24.04 Linux baseline. Use it instead of the disabled legacy
`counterstrikeglobaloffensive` / `csgo` app `740` surface.

```bash
alphagsm myserver create cs2server
```

See the [counterstrike2](counterstrike2.md) guide for full details.
