# American Truck Simulator

This guide covers the `atsserver` module in AlphaGSM.

## Requirements

- SteamCMD runtime libraries (`lib32gcc-s1`, `lib32stdc++6`)
- Exported ATS server packages/settings from an owned American Truck Simulator client install; the anonymous dedicated-server payload alone is not enough to finish startup
- Python packages from `requirements.txt`

## Quick Start

Create the server:

```bash
alphagsm myatsserve create atsserver
```

Run setup:

```bash
alphagsm myatsserve setup
```

Start it:

```bash
alphagsm myatsserve start
```

Check it:

```bash
alphagsm myatsserve status
```

Stop it:

```bash
alphagsm myatsserve stop
```

## Setup Details

Setup configures:

- the game port (default 27016)
- the install directory
- SteamCMD downloads the server files

This server is supported in `ENABLED (BYO)` mode. The dedicated server still
expects the exported server-packages/settings payload generated by the full
game client. If startup logs report `Server packages file not found`, run
`export_server_packages` from an owned ATS client and stage the resulting
files before retrying AlphaGSM startup.

## Useful Commands

```bash
alphagsm myatsserve update
alphagsm myatsserve backup
```

## Developer Notes

### Run File

- **Executable**: `bin/linux_x64/americantruck_server`
- **Location**: `<install_dir>/bin/linux_x64/americantruck_server`
- **Engine**: Custom (SteamCMD)
- **SteamCMD App ID**: `2239530`

Official SCS dedicated-server documentation says the dedicated app can be
downloaded anonymously, but first launch still requires `server_packages.sii`
and `server_packages.dat` exported from a real client profile via
`export_server_packages`. Stage those files into
`<install_dir>/.local/share/American Truck Simulator/` before `start`.

### Server Configuration

- **Config file**: `server_config.sii`
- **Template**: See [server-templates/atsserver/](../server-templates/atsserver/) if available

### Maps and Mods

- **Map directory**: Check game documentation
- **Mod directory**: Check game documentation
- **Workshop support**: No
